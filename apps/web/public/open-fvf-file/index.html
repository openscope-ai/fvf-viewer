How to Open a .fvf File in Your Browser

A .fvf (FVF) file is a binary waveform capture recorded by portable ScopeMeter test instruments. FVF Viewer enables you to open, display, and measure these captures directly in modern web browsers without installing desktop software, configuring drivers, or uploading sensitive capture bytes to external servers.

What is a .fvf File?

ScopeMeter handheld oscilloscopes and industrial test tools record waveform traces and instrument setups to compact binary files with the .fvf extension. Each valid file begins with the signature bytes FV.FVF followed by binary records encoding:

  • Header and Instrument Descriptors: Instrument model numbers, firmware configuration, and acquisition timestamps.
  • Channel Settings: Vertical sensitivity (voltage or current scaling), probe attenuation, channel labels (e.g., Input A, Input B, or German Eingang A), and canonical SI units.
  • Timebase Metadata: Horizontal time-per-division settings spanning nanoseconds, microseconds, milliseconds, seconds, or minutes per division.
  • Sample Payloads: Stored raw sample sequences — typically 500 up to 250,000 points per channel — encoded as fixed-point integers.

100% Client-Side Privacy: Nothing Is Ever Uploaded

Zero Network Transmission of Waveform Data

Unlike cloud analytics services, FVF Viewer never uploads your waveform captures to a remote server. The proprietary binary file is parsed entirely inside your browser's memory using a high-performance WebAssembly (Rust/Wasm) engine running within an isolated Web Worker. Your engineering signals, proprietary equipment traces, and measurement records remain strictly on your local machine.

Key Features of FVF Viewer

  • High-Performance Multi-Channel Display: Smooth 60 FPS interactive waveform canvas powered by uPlot with support for simultaneous multi-channel records.
  • Adaptive Zoom and Pan: Box-zoom into signal glitches, pan through long records, and review viewport history.
  • Dual Measurement Cursors: Snapping cursors with live readouts for Δt, frequency (1/Δt), and per-channel voltage differentials.
  • Lossless Data Export: Export the complete sample table with full metadata headers to CSV, or capture high-resolution PNG screenshots.
  • Robust Format Decoding: Built-in tolerance for English and German localized headers, comma-decimal timebases, unaligned payload offsets, and non-sequential channel sets.
